# Smart Hospital & Resource Allocation System

A console-based C program developed for the **CSC 1012 Introduction to Computer Programming** course at the University of Sri Jayewardenepura.

## Project Description

The Smart Hospital & Resource Allocation System is designed to manage basic hospital activities such as patient registration, waiting time calculation, bed allocation, billing, priority management, and report generation.

## Main Features

* Patient registration and input validation
* Specialty and hospital ward management
* Waiting time calculation
* Patient priority sorting based on urgency
* Bed allocation and bed availability checking
* Patient billing and age-based discounts
* Hospital report generation
* Saving bed status using file handling
* Saving patient billing records

## C Programming Concepts Used

* 1D arrays
* 2D arrays
* Parallel arrays
* Functions
* Strings
* Loops
* Conditional statements
* Sorting
* Mathematical calculations
* Basic file handling

## Project Modules

* `main.c` – Main menu and program control
* `patient.c / patient.h` – Patient registration, display and priority management
* `hospital.c / hospital.h` – Bed allocation and bed status management
* `billing.c / billing.h` – Billing calculations
* `reports.c / reports.h` – Hospital report generation

## Data Files

* `beds_status.txt` – Stores the current bed occupancy status
* `patient_records.txt` – Stores patient billing records

## How to Run

The project can be opened and compiled using **Code::Blocks** with the provided `.cbp` project file.
